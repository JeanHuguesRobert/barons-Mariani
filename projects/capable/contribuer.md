# Contribuer à Capable

Le plan de la Campagne du Réel est public.

La contribution recherchée n'est pas seulement l'approbation. Une contradiction bien sourcée a une valeur supérieure à un accord non documenté.

## Vous pouvez contribuer en

- corrigeant une date, une heure, un nom ou une référence ;
- indiquant qu'une pièce existe ;
- démontrant qu'une pièce n'a pas le sens qui lui est attribué ;
- proposant une qualification juridique concurrente ;
- identifiant une autorité compétente oubliée ;
- signalant une demande redondante ou mal adressée ;
- proposant une meilleure question factuelle ;
- documentant un précédent ;
- contestant la structure même de la matrice.

## Format conseillé

1. **Objet** — ce qui est corrigé ou contesté ;
2. **Assertion** — formulation courte ;
3. **Source** — pièce primaire si possible ;
4. **Effet proposé** — quelle case de la matrice devrait changer ;
5. **Niveau de confiance** — certain / probable / hypothèse ;
6. **Conflit d'intérêts éventuel** — lorsqu'il est pertinent.

## Droit de réponse

Une institution ou une personne mentionnée peut proposer une correction ou un droit de réponse.

La réponse est conservée comme trace distincte ; elle ne remplace pas silencieusement les versions antérieures.

## Règle de correction

Les corrections documentées doivent être intégrées rapidement et laisser une trace de version.

## Ce que Capable ne demande pas

Capable ne demande pas aux contributeurs d'adhérer à une conclusion politique ou juridique.

Le projet demande de contribuer à une carte plus exacte.
