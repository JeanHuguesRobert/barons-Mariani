# Suicide Corse n°4 — audit de sélection des Annexes

## Principe

Les Annexes du n°4 ne doivent pas devenir une seconde copie du Corpus.

Elles ont deux fonctions :

1. rendre les affirmations du Magazine **vérifiables et contestables** ;
2. rendre les approfondissements spécialisés **navigables** sans les recopier.

## Sélection retenue

### A. Index de vérification

`manuscript/annexes-n4/00-index-verification.md`

Fonction :
- route vers les sources de dépôt et d’instruction ;
- route vers les analyses électorales ;
- route vers l’architecture des recours et les QPC ;
- route vers les sources autonomie / effectivité ;
- explicite ce qui reste dans le Corpus sans être republié.

### B. Provenance privée / alias publics

`manuscript/annexes-n4/00-provenance-privee-alias-publics.md`

Fonction :
- expliquer comment une projection publique peut rester traçable sans exposer les locators privés ;
- préserver la distinction entre existence d’une source, rôle probatoire, vérité d’une proposition et causalité.

## Exclusions assumées

Ne sont pas repris dans les Annexes n°4 :

- toutes les annexes historiques du n°3 ;
- les variantes anciennes de la requête ;
- les journaux techniques complets lorsqu’une source synthétique suffit ;
- les traces sociales déjà indexées ;
- les notes de fabrication ;
- les pistes littéraires non sélectionnées ;
- les contenus privés ou locators privés.

La sélection respecte cette séparation.

## Résultat

**AUDIT CONTENU ANNEXES : PASS.**

Ce PASS signifie :
- couverture des affirmations structurantes du Magazine ;
- navigation vers les preuves primaires ou spécialisées ;
- absence de duplication massive ;
- frontière privée/publique explicite.

Il ne signifie pas :
- validation juridique finale des sources liées ;
- audit de tous les liens lors d’un rendu ;
- validation graphique ;
- autorisation de gel.
