# Journaux de campagne

Ce répertoire accueillera les éditions successives du **Journal de campagne contre l'impossible**.

Le journal n'est pas un changelog Git. Il doit raconter ce que l'exploration a effectivement produit : percées, nouvelles pistes, corrections de la carte, refus ou réponses du Réel, outils acquis, fronts ouverts et prochaine campagne.
