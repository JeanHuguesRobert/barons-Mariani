# Journal de campagne — ouverture du numéro 4

Le numéro 4 est préparé avant le gel définitif du numéro 3 afin qu'une fois le snapshot n°3 scellé, l'enquête dispose immédiatement d'une projection suivante identifiable et publique.

Cette préparation ne préjuge ni du sommaire ni du contenu final.

Principe :

> **Le gel d'un numéro ferme une projection, jamais l'enquête.**

## État initial

- issue de construction : #90 ;
- projection : `projections/book-n4-working.yml` ;
- état : préparé, `render_ready: false` ;
- activation éditoriale : après gel explicite du n°3.

## Première tâche après le freeze du n°3

Établir un état zéro :

1. commit source exact du n°3 gelé ;
2. continuations héritées ;
3. delta intervenu après ce commit ;
4. réponses du Réel déjà reçues ;
5. nouveaux faits, contradictions et inconnues ;
6. décisions initiales : Livre / Magazine / Annexes / Continuation / hors numéro.

Le n°4 ne recopiera pas le n°3. Il repartira du Corpus vivant.
