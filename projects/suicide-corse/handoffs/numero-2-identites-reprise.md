# Paquet de reprise — Suicide Corse n°2 — Identités de Marie-Louise

## Objet

Ce document permet de reprendre dans une nouvelle conversation le chantier :

**Identités de Marie-Louise → Corpus canonique → Suicide Corse n°2**

Il doit éviter de recommencer l'enquête depuis zéro et préserver les découvertes, décisions méthodologiques et inconnues déjà établies.

L'issue GitHub **#81 — Suicide Corse n°2 — édition agile du lundi 21 septembre 2026** constitue le centre de gravité éditorial du numéro 2.

## Principe éditorial acquis

Le n°2 n'est aucunement contraint par le plan du n°1.

Chaque numéro de *Suicide Corse* est une nouvelle projection du Corpus disponible. Le plan, l'ordre, les chapitres, leur longueur et leurs fonctions peuvent donc être entièrement recomposés.

La continuité porte sur :

- les sources ;
- leur provenance ;
- les statuts épistémiques ;
- les décisions éditoriales ;
- les Continuations ;

et non sur la forme de l'édition précédente.

## Convention temporelle

Le projet distingue :

- **temps de trace** : timestamp civil exact, conservé sans modification ;
- **journée éditoriale** : journée humaine prolongée pendant la soirée et la nuit jusqu'à l'aube suivante.

Ainsi, dans le vocabulaire éditorial du projet, la nuit du 17 au 18 septembre appartient à la journée du 17 jusqu'au lever du soleil.

Pour le n°2, l'horizon de travail est le **lever du soleil du lundi 21 septembre 2026**.

## « Tous barons »

Ne pas interpréter principalement cette formule comme une revendication nobiliaire.

Dans le discours électoral de JHR, « Tous barons » appartient à une continuité politique associant notamment :

- égalité politique ;
- souveraineté populaire ;
- démocratie directe.

JHR situe cette continuité électorale depuis 2017 jusqu'en 2026.

Il faut cependant distinguer :

- le discours politique de JHR ;
- la présence de « Tous barons » sur le bulletin ;
- la transmission du bulletin par Marie-Louise ;
- les éventuelles paroles propres de Marie-Louise sur cette formule, encore à rechercher.

Ne pas lui attribuer automatiquement la doctrine de JHR.

## Discipline épistémique

Pour chaque identité, distinguer autant que possible :

`Personne`

→ `Compte / support`

→ `Adresse technique`

→ `Nom affiché`

→ `Signature éventuelle`

→ `Nom inscrit dans le document`

→ `Contexte`

→ `Date/période`

→ `Source`

→ `Statut épistémique`

Ne jamais composer silencieusement plusieurs identités indépendantes pour fabriquer une forme qui n'est attestée nulle part.

En particulier, la forme combinée :

`Marie-Louise d'Angelis, baronne Mariani`

ne doit pas être présentée comme un usage de Marie-Louise tant qu'une source ne l'atteste pas.

## Interdiction d'interprétation rétrospective

Les variations de noms constituent des faits documentaires.

Elles peuvent être riches de sens.

Elles ne constituent pas, par elles-mêmes, une preuve permettant d'inférer :

- un état psychologique ;
- une fragmentation pathologique ;
- une causalité relative au suicide ;
- une intention constante derrière tous les changements de nom.

La recherche doit prioritairement chercher les propres paroles, œuvres et usages de Marie-Louise.
