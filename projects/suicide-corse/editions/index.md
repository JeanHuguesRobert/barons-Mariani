# Index des éditions

Aucune édition figée n'est encore enregistrée.

La première édition réellement rendue devra recevoir une identité stable et référencer au minimum :

- date du build ;
- commit source ;
- contrat de projection ;
- version du renderer ;
- artefacts HTML/PDF disponibles ;
- éventuel tag ou release ;
- statut de revue.

Une édition figée ne doit pas être réécrite silencieusement. Toute correction substantielle produit une nouvelle édition ou un erratum explicitement traçable.

Voir #44 pour le premier snapshot hebdomadaire.
