# Annexes n°4 — guide de vérification

Les Annexes ne recopient ni le Magazine ni l'ensemble du Corpus.

Elles répondent à une question plus simple :

> **si je veux vérifier, contester ou approfondir ce que je viens de lire, où dois-je aller ?**

La sélection du n°4 suit quatre niveaux.

## A — Vérifier le changement d'état du dossier 2026-6589 SEN

### Requête et enregistrement

- [Requête canonique déposée](../../../research/senatoriales-2026/requete-conseil-constitutionnel.md)
- [Reprise du 8 octobre — preuve d'enregistrement 2026-6589 SEN](../../../research/senatoriales-2026/reprise-2026-10-08.md)
- [Suivi de l'instruction](../../../research/senatoriales-2026/suivi-instruction-conseil-constitutionnel.md)
- [Gel du PDF effectivement transmis](../../../research/senatoriales-2026/handoffs/2026-10-07-pdf-conseil-constitutionnel-freeze.md)

Ces sources permettent de distinguer :

~~~text
texte existant
→ PDF matérialisé
→ transmission
→ réception
→ enregistrement
→ instruction
~~~

Aucune de ces transitions ne vaut, à elle seule, décision sur la recevabilité ou sur le fond.

Cette couche permet de vérifier la distinction :

~~~text
compétence reconnue
≠ accès à la compétence
≠ exercice
≠ effets
≠ correction
~~~

Elle ne transforme pas le contentieux électoral en preuve en faveur de l'autonomie. Elle teste seulement la persistance d'une même question d'effectivité à une autre échelle.

## D — Vérifier sans divulguer

La note [Provenance privée, référence publique](00-provenance-privee-alias-publics.md) explique la nouvelle frontière documentaire appliquée aux sources relatives à Marie-Louise.

~~~text
source privée réelle
→ source canonique privée
→ alias public opaque
→ projection publique
~~~

Règle :

> **traçabilité ≠ divulgation intégrale**

L'alias public permet de maintenir une chaîne de provenance sans exposer le locator privé. Il n'établit jamais automatiquement la vérité d'une proposition ni une causalité.

## Ce qui n'est pas republié dans les Annexes n°4

Restent dans le Corpus, sans être réinsérés dans cette édition :

- l'intégralité des anciennes annexes du n°3 ;
- les pièces brutes déjà correctement indexées ;
- les journaux techniques dont la fonction est seulement de reconstruire un incident ;
- la publication Facebook du bulletin ;
- les variantes historiques de la requête ;
- les notes de fabrication et pistes littéraires non retenues dans le Magazine ;
- les documents privés ou locators privés de Marie-Louise.

Le critère est fonctionnel :

~~~text
nécessaire pour vérifier le n°4
→ rendre navigable depuis les Annexes

déjà vérifiable dans le Corpus sans gain éditorial à le recopier
→ laisser dans le Corpus
~~~
