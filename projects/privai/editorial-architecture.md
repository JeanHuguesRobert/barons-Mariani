# PrivAI — architecture éditoriale

PrivAI réemploie les invariants du Livre Vivant sans réécrire son moteur.

```text
sources / traces / controverses / cas
→ qualification
→ corpus vivant
→ projection
→ revue
→ gel
→ édition immuable
→ réponse du Réel
→ nouvelles traces
```

## Triptyque

> **Le corps principal raconte. Le magazine actualise. Les annexes démontrent.**

### Livre

Le Livre expose la thèse de souveraineté humaine, l'asymétrie entre individus et personnes morales augmentées, les contre-pouvoirs cognitifs et les conditions d'une AI Safety démocratique.

### Magazine

Le Magazine accueille :

- nouvelles capacités de modèles ;
- nouvelles pratiques institutionnelles ;
- décisions de justice et réglementation ;
- expériences de jumeaux et agents personnels ;
- incidents et cas de capture ;
- critiques de la doctrine PrivAI ;
- réponses du Réel aux prototypes.

### Annexes

Les annexes portent :

- sources primaires ;
- textes juridiques ;
- matrices d'asymétrie ;
- protocoles de test ;
- modèles de menace ;
- benchmarks ;
- revues adverses ;
- glossaire ;
- cartographie des dépendances techniques ;
- limites connues.

## Principe éditorial

PrivAI ne publie pas une guerre entre "humains" et "IA".

Il étudie une question plus précise :

> **Comment conserver une souveraineté humaine effective lorsque des acteurs collectifs disposent d'une amplification artificielle très supérieure à celle des individus ?**

## Numéro 1

Le n°1 introduit la thèse, montre qu'elle existe déjà dans le Corpus, et transforme la doctrine en programme de Reality Tests.
