# Annexes et Dossiers Probatoires de 1755

Les annexes du Livre Vivant **1755** rassemblent les pièces documentaires, les transcriptions critiques d'archives et les analyses institutionnelles spécialisées qui fondent scientifiquement le récit historique du Manuscrit.
