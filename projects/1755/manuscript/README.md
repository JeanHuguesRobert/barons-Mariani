# Manuscrit fondamental de 1755 (Projection n1)

Le manuscrit fondamental de **1755** constitue la Face 1 du Livre Vivant. Il articule l'analyse historique de la séquence révolutionnaire corse et son insertion dans l'histoire universelle des idées politiques.
