# Commons — Surface web publique

Ce dossier contient la surface de lecture statique publique de **Commons** (Phase 1).

## Fichiers de la surface

- `index.html` : Accueil du Livre Vivant, questions fondatrices, présentation de n°1, cas et chronologie.
- `n1.html` : Lecture intégrale du numéro 1 « Des communaux au cloud » (les 4 mouvements, l'Épreuve de l'Ouvert-Possible, question de clôture).
- `cases.html` : Fiches détaillées des 8 études de cas selon le modèle conceptuel unifié.
- `chronologie.html` : Frise chronologique jalonnée de 1217 à 2026.
- `sources.html` : Sources documentaires, 3 régimes de preuve et cartographie d'amitié (*Friends before competitors*).
- `glossaire.html` : Définitions conceptuelles des termes clés des biens communs.
- `contribuer.html` : Protocole de contribution, signalement d'erreurs et soumission d'objections.
- `mentions.html` : Mentions légales, cadre C.O.R.S.I.C.A. / Institut Mariani, licence CC BY-SA 4.0.
- `styles.css` : Feuille de style accessible, sobre, responsive et avec gestion automatique des thèmes clair/sombre.
- `llms.txt` : Manifeste machine-readable d'orientation pour les agents d'IA.
- `robots.txt` & `sitemap.xml` : Fichiers d'indexation pour robots d'exploration.
