# Commons n°1 — Les biens communs, du passé au futur

## Sous-thème

> **Des communaux au cloud**

## Fil directeur

Les biens communs ne sont pas une invention récente du numérique.

Ils constituent une ancienne technologie sociale de gestion de ressources et de capacités partagées.

Le substrat change :

```text
terre
→ eau
→ pâturage
→ forêt
→ connaissance
→ code
→ données
→ énergie
→ compute
→ cognition
```

mais reviennent des questions comparables :

```text
accès
usage
entretien
contribution
exclusion
règles
gouvernance
capture
transmission
```

## Quatre mouvements rédigés

1. [**Mouvement I — Héritages**](01-heritages.md) : Les communaux, la coutume et l'art de gouverner le partagé (sources : Carta de Foresta 1217, Thompson, Bloch, Vivier, Huertas de Valence).
2. [**Mouvement II — Captures et destructions**](02-captures-et-enclosures.md) : Enclosures, expropriation légale et déconstruction de la fable de la tragédie d'Hardin (Polanyi, Boyle, Ciriacy-Wantrup).
3. [**Mouvement III — Renaissances**](03-renaissances.md) : La rupture Ostrom, le logiciel libre, le copyleft comme contre-enclosure juridique et l'explosion de Wikipédia (Stallman, Benkler, Hess & Ostrom).
4. [**Mouvement IV — Futurs possibles**](04-futurs-possibles.md) : Énergie distribuée (FractaVolta), souveraineté des données, compute/modèles d'IA, Cogentia Commons et l'épreuve de l'Ouvert-Possible.

## Tension centrale

Le numéro doit conserver une distinction fondamentale :

> **Tout ce qui peut être partagé ne doit pas nécessairement être mis en commun.**

Un futur des communs digne de ce nom doit aussi protéger :

- autonomie individuelle ;
- consentement ;
- retrait ;
- pluralité institutionnelle ;
- droit à la dissidence ;
- espaces privés ;
- souveraineté personnelle.

## Méthode du numéro — Friends before competitors

Le n°1 ne traite pas l'état de l'art comme une compétition de priorité.

Pour chaque tradition, théorie, communauté, standard, projet ou implémentation matériellement pertinent, l'enquête demande d'abord :

1. quelle parenté existe ;
2. ce qui a déjà été démontré, testé ou maintenu ;
3. ce qui peut être réutilisé ou composé ;
4. quelles limites et incompatibilités doivent rester visibles ;
5. quel résidu mérite encore exploration.

Le cas échéant, une **friendship map** accompagne l'état de l'art :

```text
ami / travail
→ parenté
→ preuves / Reality Tests disponibles
→ capacités réutilisables
→ composition possible
→ incompatibilités
→ résidu
```

La différenciation et l'éventuelle originalité sont examinées après cette cartographie, et seulement lorsqu'elles sont utiles.

Formule de travail :

> **Un antécédent est du Réel déjà payé par d'autres — à vérifier, attribuer et, si possible, rendre composable.**
