# Corse furtive — dossier d'enquête

Ce dossier reçoit les éléments probatoires, calculs et protocoles du chapitre **La Corse furtive**.

## Principe

**Furtivité systémique** : les éléments du phénomène sont visibles séparément, mais leur structure collective reste sous le seuil ordinaire de perception tant qu'ils ne sont pas agrégés.

Ce terme ne présuppose ni clandestinité, ni coordination consciente, ni illégalité.

## Probes ouverts

### CF-P1 — cadres coloniaux

Questions à fermer : source historiographique des chiffres de 1934 ; population de référence exacte ; périmètre de « cadres militaires et fonctionnaires » ; distinction officiers / sous-officiers / soldats / fonctionnaires ; reconstruction des facteurs de surreprésentation ; explication de l'écart entre environ ×27 et le facteur ~×66 rapporté par le Principal.

Point de départ :
https://academiesciencesmoralesetpolitiques.fr/2019/01/21/laurent-stefanini-la-corse-en-france-250-ans-dadhesion-consentie/

### CF-P2 — agrégés

Objectif : tester une éventuelle surreprésentation corse parmi des cohortes d'agrégés sans disposer d'une variable administrative « origine corse ».

Variables/proxys candidats : naissance en Corse ; ascendance explicitement sourcée ; scolarisation en Corse ; patronyme ; prénom ; séquence de prénoms et prénom d'usage ; trajectoires biographiques.

L'estimation devra comporter au moins un **plancher documentaire** fondé sur les cas explicitement établis, une **estimation probabiliste** séparée si les proxys peuvent être calibrés, une ou plusieurs **populations témoins**, et des analyses par cohorte.

### CF-P3 — anthroponymie

Source de calibration prioritaire :
https://www.insee.fr/fr/statistiques/6483268

Faits de départ documentés par l'Insee pour la période depuis 1945 : Jean et Marie persistent plus longtemps en Corse qu'au niveau national ; en 2021, les prénoms composés concernent 15 % des garçons et 10 % des filles en Corse contre 2 % au niveau national ; environ 700 Jean-Baptiste sont nés en Corse depuis 1945.

Précaution : le trait d'union administratif n'épuise pas le phénomène d'usage. Le Corpus documente le cas contemporain Jean, Hugues, Noël → usage Jean-Hugues, ainsi que les variantes historiques de Louis Hugues Ferdinand Marie Mariani.

## Formule de mesure minimale

Pour une catégorie C et une population de référence R :

F_C = P(Corse | C) / P(Corse | R)

Le choix de R doit toujours être explicite. Deux facteurs calculés avec des dénominateurs différents ne sont pas contradictoires avant harmonisation.

## Règle de publication

~~~text
proxy ≠ preuve individuelle
absence de statistique ≠ absence de phénomène
corrélation ≠ mécanisme causal
surreprésentation ≠ coordination
~~~

Les annexes doivent conserver les données brutes, les règles de codage, les cas incertains et les contre-exemples.
