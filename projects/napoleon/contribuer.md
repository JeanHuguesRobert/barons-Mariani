# Contribuer

Le Livre Vivant Napoléon est ouvert aux corrections et contradictions.

Contributions utiles :

- source primaire manquante ;
- erreur de date ou de localisation ;
- attribution douteuse ;
- lecture historiographique concurrente ;
- contre-exemple à une règle stratégique ;
- critique du Twin provisoire ;
- proposition de Reality Test ;
- carte, chronologie ou jeu de données sourcé.

Une contribution qui invalide une hypothèse du Twin est particulièrement utile.

## Séparation obligatoire

Toute contribution doit préciser si elle vise :

- un fait historique ;
- une interprétation historiographique ;
- une hypothèse du Twin ;
- une application contemporaine.

## Droit de correction

Toute correction intégrée doit laisser une trace de version.
