# Napoléon — architecture

## 1. Quatre couches

### A — Sources primaires
Correspondance, proclamations, ordres, archives, textes juridiques, cartes, rapports et documents contemporains.

### B — Histoire et historiographie
Chronologie, campagnes, institutions, administration, droit, économie, société, controverses.

### C — Provisional Cogentia Twin
Modèle stratégique explicitement provisoire, sourcé et falsifiable.

### D — Reality Tests
Applications contemporaines documentées, avec séparation stricte entre analogie et identité de situation.

## 2. Livre / journal / annexes / site

- **Livre** : récit synthétique ;
- **Journal** : découvertes, controverses, corrections ;
- **Annexes** : sources, cartes, tableaux, bibliographies ;
- **Site** : recherche, chronologie, campagnes, concepts, Twin et tests.

## 3. Registre épistémique

Chaque assertion importante doit pouvoir recevoir un statut :

- `PRIMARY_SOURCE`
- `SECONDARY_CONSENSUS`
- `CONTESTED`
- `INFERENCE`
- `TWIN_HYPOTHESIS`
- `UNKNOWN`

## 4. Succès et échecs

Le corpus du Twin doit inclure :

- Ulm ;
- Austerlitz ;
- Iéna-Auerstaedt ;
- Wagram ;

mais aussi :

- Saint-Domingue ;
- Espagne ;
- Acre ;
- Russie ;
- Leipzig ;
- Waterloo.

Un Twin entraîné seulement sur les victoires serait structurellement biaisé.

## 5. Règle de transposition

Une similitude structurelle doit être explicitée avant toute transposition :

`situation historique → invariant supposé → différences matérielles → transposition possible → limites`.

## 6. Revue adverse

Toute thèse stratégique importante doit recevoir :

- une lecture favorable ;
- une objection historique ;
- une objection logistique ;
- une objection politique ;
- une objection juridique contemporaine lorsqu'une application actuelle est proposée.
