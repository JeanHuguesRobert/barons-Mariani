# Napoléon

**Napoléon** est un Livre Vivant consacré à Napoléon Bonaparte comme objet historique, stratégique et historiographique, avec une couche expérimentale distincte : le **Provisional Cogentia Twin — Napoléon Bonaparte** hébergé par Agent JHN.

Site public cible : **https://napoleon.acorsica.org**

## Principe directeur

Le projet maintient quatre plans séparés :

1. **Napoléon historique** — faits, actes, correspondances, décisions, campagnes ;
2. **Historiographie** — interprétations, controverses, écoles et révisions ;
3. **Twin provisoire** — inférences stratégiques explicitement probabilistes ;
4. **Applications contemporaines** — analogies et transpositions, jamais confondues avec les faits historiques.

## Pourquoi un Livre Vivant

Le sujet est trop vaste et trop controversé pour prétendre être clos.

Le Livre Vivant permet de :

- publier les sources au fil de l'eau ;
- conserver les désaccords historiographiques visibles ;
- documenter les erreurs et révisions ;
- tester le Twin provisoire sur des situations contemporaines ;
- confronter ses recommandations aux succès **et** aux échecs napoléoniens ;
- inviter historiens, militaires, juristes, lecteurs et agents IA à corriger le corpus.

## Première application

La première expérimentation documentée est la **Campagne du Réel** du Livre Vivant *Capable*.

Ce lien est un test, pas une fusion des deux livres.

## Règle de prudence

Le projet ne transforme pas Napoléon en oracle.

Un échec historique est une source d'apprentissage au même titre qu'une victoire.
