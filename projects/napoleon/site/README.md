# napoleon.acorsica.org — contrat de publication

Domaine cible : **https://napoleon.acorsica.org**

## MVP

- `/` — présentation du Livre Vivant ;
- `/chronologie/` — chronologie ;
- `/campagnes/` — campagnes militaires et politiques ;
- `/sources/` — registre de sources ;
- `/controverses/` — désaccords historiographiques ;
- `/twin/` — statut, règles et limites du Twin provisoire ;
- `/reality-tests/` — applications contemporaines ;
- `/contribuer/` — corrections et contradictions.

## Règles UX

Chaque contenu doit rendre visible son statut épistémique.

Un lecteur doit pouvoir distinguer en un coup d'œil :

- fait sourcé ;
- interprétation ;
- controverse ;
- hypothèse du Twin ;
- analogie contemporaine.

## Source-first

Le site est une projection du Corpus GitHub.

## Accessibilité

Le contenu principal doit rester lisible sans JavaScript.
