**Registre de preuve à alimenter :** identifiant d'activité, date, auteur/source, événement, état, lien de preuve, contradiction, révision. L'absence de preuve doit rester visible ; aucune donnée privée de détenteurs d'objets n'est publiable sans base appropriée.
