# Référentiel d’identité — Barons Mariani

Ce répertoire constitue le point d’entrée canonique des travaux consacrés aux
identités liées aux **Barons Mariani**.

Il distingue notamment :

- l’identité d’état civil ;
- les noms d’usage, pseudonymes et identités publiques ;
- les dénominations familiales et historiques ;
- les dénominations institutionnelles ;
- les identifiants et signes numériques ;
- les représentations produites par des tiers ;
- les qualifications juridiques susceptibles de s’appliquer à ces différents objets.

Le référentiel ne présuppose ni qu’une variante constitue une erreur, ni qu’un
usage établit à lui seul un droit particulier.
