# Tableau I — LES MARIANI

## Statut

Reconstruction de travail du **Tableau I — LES MARIANI** de Jacques Meurgey, *Les Barons Mariani et leurs alliances* (1933), à partir de deux photographies du tableau plié retrouvées dans le Google Doc **Pièces Mariani DRAC**, transmis à Éléonore Bozzi le 30 avril 2025.

Localisation technique actuelle :

- export PDF du Google Doc, p. 48 : vue couvrant les générations anciennes et une partie des branches collatérales ;
- export PDF, p. 49 : vue couvrant principalement la descendance du premier baron et des annotations manuscrites postérieures.

**Attention :** 48–49 sont des numéros d'export PDF, pas une pagination papier de Meurgey.

Cette reconstruction distingue :

- **[imprimé]** : lecture du tableau imprimé de 1933 ;
- **[manuscrit]** : annotation portée ultérieurement sur l'exemplaire photographié ;
- **[lecture incertaine]** : graphie non fermée au premier examen visuel.

Elle ne normalise pas silencieusement les noms.

## G. Comparaison immédiate avec le graphe canonique du Corpus

### Concordances fortes

Le Tableau I confirme ou renforce plusieurs données déjà présentes :

- **Antoine-Dominique Mariani : 1776–1845** ;
- **Louis-Thomas : 1815–1890** ;
- existence d'un frère **Louis-Hugues Ferdinand**, époux d'une **d'Angelis** ;
- **Hyacinthe-Louis-Joseph : 1827–1894**, ce qui donne un appui secondaire précis à l'une des dates actuellement en conflit dans le Corpus ;
- **Hyacinthe → Albert**, épouse **Sophie Fantauzzi** ;
- **Louis-Hugues → Pierre**, épouse **de Casabianca** ;
- **Pierre → Louis + Marie-Louise** ;
- annotation manuscrite **Marie-Louise → Jean Robert → Marguerite**, compatible avec la chaîne familiale documentée par ailleurs.

### Ajouts significatifs

Le graphe canonique `musee-mariani/mariani/personnes.tsv` est actuellement très centré sur la branche menant à Jean Hugues. Le tableau apporte immédiatement :

1. **Louise Dard d'Espinat**, épouse du premier baron ;
2. une fratrie beaucoup plus large autour de Louis-Thomas, Louis-Hugues, Hyacinthe et Madeleine ;
3. une descendance de Louis-Thomas passant par **Fernande Mariani** puis **d'Adhémar**, **Langlade**, **Hainguerlot** et **Terlinden** ;
4. **Joseph Mariani (1901–1921)** dans la branche Albert ;
5. plusieurs ramifications **Filippini / Fantauzzi**.

Ces personnes ne doivent pas être injectées automatiquement dans le TSV canonique tant que les lectures visuelles et les relations topologiques du tableau n'ont pas fait l'objet d'une deuxième passe.

### Discordances / points à fermer

- Le Corpus conserve actuellement des dates discordantes pour **Louis-Hugues** ; le Tableau I ne donne pas de dates lisibles pour lui sur la vue actuelle.
- Le Corpus donne **Hyacinthe 1827–1894 / 1884** selon sources secondaires ; le Tableau I imprime **1827–1894**, ce qui renforce 1894 sans constituer une source primaire.
- Le nombre exact des huit enfants du premier baron et l'identité des trois enfants signalés manuscritement comme morts sans postérité doivent être vérifiés.
- Les noms complets des conjoints de Louis-Thomas et de Fernande Mariani doivent être relus à plus forte résolution.
- La continuation à droite de la branche Filippini/Fantauzzi est partiellement coupée.
