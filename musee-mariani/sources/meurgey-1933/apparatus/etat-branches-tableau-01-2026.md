## Premier enseignement

Le Tableau I produit immédiatement trois situations différentes :

~~~text
A. disparition du patronyme + forte survie généalogique
   → Louis-Thomas → Madeleine → d’Adhémar → ...

B. disparition probable d'une sous-branche
   → Hyacinthe → Albert → Joseph

C. survie généalogique + réancrage contemporain en Corse
   → Louis-Hugues → Pierre → Marie-Louise → Marguerite → Jean Hugues
~~~

Ainsi :

> **disparition du nom ≠ extinction de la descendance ≠ disparition du lien territorial**

Ces trois variables doivent rester séparées dans toute l'enquête.

## Branche Louis-Thomas / Madeleine : résultat déjà robuste

La ligne par Madeleine Mariani est la mieux prolongée à ce stade :

~~~text
Louis-Thomas Mariani
→ Madeleine Mariani
→ Thérèse d’Adhémar → Girot de Langlade → descendants vivants masqués
→ Blanche d’Adhémar
   → Hainguerlot → descendants vivants
   → Madeleine Hainguerlot
      → André Terlinden
         → neuf enfants selon sources généalogiques secondaires
         → plusieurs sous-branches avec descendance
         → Jacqueline Terlinden
            → Jean Compagnon
               → six enfants, dont Antoine Compagnon
~~~

La descendance contemporaine est donc **non seulement subsistante mais nombreuse**.

## Branche Hyacinthe : hypothèse d'extinction à tester

Le Tableau I donne :

~~~text
Hyacinthe-Louis-Joseph Mariani (1827–1894)

→ Albert Mariani
~~~

À ce stade, aucune autre descendance de ce couple n'a été identifiée dans la recherche publique initiale.

Statut correct :

> **PROBABLEMENT ÉTEINTE — à confirmer.**

Le dossier ne doit pas convertir l'absence de résultat en preuve d'extinction.
