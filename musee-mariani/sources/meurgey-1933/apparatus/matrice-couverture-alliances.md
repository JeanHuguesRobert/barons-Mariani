# Matrice de couverture des alliances directes

## Source

Meurgey, p. 2, donne explicitement les « alliances directes des Mariani » qu'il dit avoir retrouvées.

Cette matrice transforme cette liste en **plan d'exploration en largeur**.

## Lecture de couverture

Les branches actuellement très étudiées sont **Arrighi, Adhémar, Casabianca, Filippini, Fantauzzi**.

Les angles sous-explorés à fort rendement de largeur sont :

1. **Leoni** — permet de tester la revendication d'origine vénitienne ;
2. **Maltedo** — alliance directe totalement non localisée ;
3. **Savelli** — branche cortenaise ancienne ;
4. **Gaffori** — autre grande famille de Corte, utile pour cartographier le réseau local ;
5. **Dard d'Espinay / Maneil** — ouvre le réseau hollandais et Limburg-Stirum ;
6. **Alesina de Schweitzer** — ouvre le réseau allemand/Sayn-Wittgenstein ;
7. **Louvencourt** — permet de mieux comprendre la branche Hyacinthe / Albert.

## Règle de progression

Maintenir simultanément :

- **2 pistes de profondeur** : fermeture d'un maillon précis ;
- **2 pistes de largeur** : ouverture/qualification de familles encore peu étudiées ;
- **1 piste patrimoniale** : bien, succession, donation, transfert ;
- **1 piste territoriale** : où la branche a effectivement vécu/agi.

Ce ratio est une heuristique de travail, non une contrainte rigide.


## Cas transversal — Mariani / Filippini / Gaffori / Cochinchine

Une branche collatérale du premier baron ouvre un axe particulièrement utile :

```text
Joseph-Marie Mariani
× Marie-Madeleine Arrighi de Casanova
→ Maria Scolastica Mariani (1787–)
  × Michelangelo Filippini
    ├── Marie-Magdeleine Filippini
    │   × François-Marie Gaffori
    │   → descendance Gaffori
    └── Giacinto / Hyacinthe Filippini
        × Marie-Apolline Gaffori
        → Charles Louis Filippini (1834–1887)
```

Les sources secondaires publiques donnent à **Charles Louis Filippini** une trajectoire exceptionnelle :

- avocat ;
- maire de Corte ;
- préfet ;
- gouverneur en Cochinchine ;
- mort à Saïgon en 1887.

### Qualification généalogique

Maria Scolastica est une fille de Joseph-Marie Mariani et sœur/collatérale du premier baron Antoine-Dominique.

Cette branche relève donc du **réseau familial Mariani élargi**, pas de la descendance du premier baron.

### Intérêt transversal

Le réseau cortenais produit ici simultanément :

```text
ancrage local à Corte
→ fonctions judiciaires / municipales
→ préfectorale
→ administration coloniale
→ Saïgon
```

C'est un candidat fort pour le croisement Musée Mariani ↔ DIASPORA ↔ histoire coloniale.
