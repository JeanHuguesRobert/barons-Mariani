# Personnes — index généalogique du Musée Mariani

## Objet

Cet index est le **point d’entrée canonique des personnes** du sous-corpus généalogique du Musée Mariani.

Il ne constitue pas un arbre généalogique définitif. Il référence des personnes, leurs principaux liens documentaires et l’état actuel de la preuve. Les dates, filiations et lieux non fermés par des sources primaires doivent rester explicitement qualifiés.

L’index ne s’arrête pas aux ancêtres historiques : les personnes contemporaines pertinentes pour la continuité familiale, patrimoniale, documentaire ou institutionnelle y ont également leur place. Pour les personnes vivantes, seules les informations publiques ou nécessaires à la fonction documentaire de l’index doivent y être stabilisées.

Méthode : [`Notices — famille étendue Mariani / de Casabianca / d’Angelis`](../methodes/notices_famille_etendue.md).  
Grille de preuve : [`Preuves et incertitudes`](../notes-critiques/preuves-et-incertitudes.md).

## Convention de preuve

| Code | Sens dans cet index |
|---|---|
| **E** | élément établi par une source primaire ou institutionnelle suffisamment précise |
| **P** | fait probable / convergence solide, encore à consolider |
| **S** | donnée provenant principalement d’une source secondaire ou généalogique |
| **D** | données discordantes entre sources |
| **O** | question ouverte / élément à fermer |

Ces codes sont des raccourcis de navigation. Ils ne remplacent pas l’appareil critique de chaque notice.

## Branche de Casabianca — mémoire patrimoniale contemporaine

Les éléments suivants sont conservés comme **mémoire directe JHR à corroborer**, sauf indication contraire :

- la maison familiale de Venzolasca et les terrains alentour ont été vendus ; le tombeau / caveau familial a été conservé ;
- l'existence du caveau familial de Venzolasca est indépendamment corroborée par le faire-part de Pierre de Casabianca (2014), qui indique qu'il devait y reposer ;
- Claire de Casabianca, dite **« Clairette »**, a épousé **Philippe Boisseau** ; ce mariage est indépendamment corroboré par le faire-part de Philippe Boisseau (2019) ;
- **Marc Boisseau** est un fils de Claire et Philippe ; le faire-part de Philippe le cite parmi leurs enfants ;
- selon JHR, Marc Boisseau a déposé discrètement, sans publicité familiale préalable (« en catimini » dans le souvenir rapporté), les cendres de Rose-Marie de Casabianca (« Moussia ») dans le tombeau familial de Venzolasca ; les circonstances précises, la date et une éventuelle trace documentaire restent à rechercher.

Ces éléments distinguent trois niveaux : **patrimoine vendu** (mémoire JHR à documenter), **tombeau familial conservé** (mémoire JHR + trace publique de son existence), et **dépôt des cendres de Moussia par Marc Boisseau** (témoignage JHR à corroborer). Ils ne doivent pas être transformés en faits publics plus précis sans source supplémentaire.

## Personnes contemporaines et sous-corpus spécialisés

Certaines personnes de l’index sont suffisamment documentées pour disposer d’un **sous-corpus propre**. Dans ce cas, la future notice individuelle du Musée ne doit pas absorber ni dupliquer ce sous-corpus : elle doit servir de nœud de navigation entre la généalogie et les documents spécialisés.

Le cas de **Marie-Louise Isabelle Garance Robert** est déjà structurant :

- [`memory/marie-louise/README.md`](../../memory/marie-louise/README.md) est l’index de mémoire et de sources ;
- [`memory/marie-louise/carte.md`](../../memory/marie-louise/carte.md) est la carte documentaire évolutive ;
- [`projects/suicide-corse/README.md`](../../projects/suicide-corse/README.md) ouvre une projection éditoriale et de recherche à partir de ce corpus, sans remplacer les traces sources ;
- les dossiers [`works/`](../../memory/marie-louise/works/), [`elections/`](../../memory/marie-louise/elections/) et la matrice du possible documentent des dimensions particulières de son parcours.

Cette distinction doit être maintenue :

```text
personne
→ notice canonique Musée
→ carte documentaire / sources
→ dossiers spécialisés
→ projections éditoriales ou de recherche
```

Pour une personne vivante, notamment **Jean Hugues Noël Robert**, la notice publique future devra rester limitée aux éléments publics, pertinents pour le corpus et proportionnés à sa fonction documentaire ; la mémoire privée ne doit pas être aspirée automatiquement dans la publication.

## Règle de maintenance

Une personne peut entrer dans cet index avant que sa notice soit créée, à condition que son existence et sa pertinence pour le corpus soient suffisamment documentées et que les incertitudes soient visibles.

Lorsqu’une notice individuelle est créée :

1. remplacer le lien provisoire par la notice canonique ;
2. conserver les liens vers les dossiers transversaux pertinents ;
3. mettre à jour le statut documentaire et le code de preuve ;
4. ne jamais faire disparaître silencieusement une discordance : la fermer par source ou la conserver comme question ouverte ;
5. lorsqu’un sous-corpus spécialisé existe, relier la notice à son index canonique plutôt que dupliquer son contenu.

Le but est un index **navigable, corrigible et probatoire**, non une généalogie déclarative figée.
