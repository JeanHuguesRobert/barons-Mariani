# Dossier Arrighi de Casanova

Parent : [Musée Mariani — préfiguration](../README.md).

Sous-corpus canonique consacré à l'alliance **Arrighi de Casanova**, ouverte par le dépouillement du **Tableau II** de Jacques Meurgey, *Les Barons Mariani et leurs alliances* (1933).

## Pourquoi ce dossier existe

L'enquête 1933→2026 montre que les alliances ne peuvent pas être traitées comme de simples marges de la généalogie Mariani.

Le cas Arrighi de Casanova combine :

- une famille corse historiquement liée à Corte ;
- une branche ducale de Padoue aujourd'hui éteinte en titre ;
- une descendance du dernier duc poursuivie par les femmes ;
- une famille Arrighi de Casanova elle-même encore décrite comme subsistante par une branche cadette ;
- une maison historique toujours existante à Corte, aujourd'hui propriété de la commune.

Il constitue donc un cas particulièrement riche pour distinguer :

~~~text
titre
≠ patronyme
≠ descendance
≠ propriété
≠ ancrage territorial
≠ mémoire
~~~

## État actuel

La reconstruction du Tableau II est en première passe.

Deux branches doivent être étudiées séparément :

1. **branche ducale** : Hyacinthe → Jean-Thomas → Ernest → Marie-Adèle-Henriette → Caraman ;
2. **branche cadette subsistante** : issue de Jean-Baptiste Philippe Arrighi de Casanova, à reconstruire jusqu'aux générations contemporaines sans exposer indûment les personnes vivantes.

## Questions ouvertes

- Comment les Arrighi de Casanova se raccordent-ils exactement aux deux alliances Arrighi déjà visibles dans le Tableau I Mariani ?
- Quand et par quel mécanisme la Maison Arrighi de Casanova de Corte est-elle devenue propriété communale ?
- Quels liens résidentiels, patrimoniaux, culturels ou institutionnels les branches contemporaines ont-elles conservés avec la Corse ?
- Quelle est la continuation précise des annotations manuscrites ajoutées sur l'exemplaire de Meurgey après 1933 ?

## Règle de méthode

Le dossier ne confond jamais :

- extinction d'un titre ;
- extinction d'une lignée masculine ;
- extinction de toute descendance ;
- disparition du patronyme ;
- perte de propriété ;
- disparition du lien avec la Corse.

Chaque variable doit être documentée séparément.
