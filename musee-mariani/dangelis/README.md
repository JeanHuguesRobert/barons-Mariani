# Dossier d’Angelis

Sous-corpus canonique consacré à la généalogie et à l'histoire familiale d’Angelis. Il alimente notamment la projection `projects/suicide-corse/manuscript/17-genealogie.md`.

## État initial

Le Corpus possède déjà un dossier de recherche généalogique et juridique substantiel : `research/relevement_nom_dangelis.md`. Il ne doit pas être déplacé ni dupliqué : le présent dossier fournit le nœud généalogique canonique auquel ce travail transversal peut se rattacher.

## Raccords déjà présents dans le Corpus

Deux interfaces avec les autres branches doivent être distinguées :

- la piste **Marie Joséphine d’Angelis → Louis-Hugues Mariani → Pierre Mariani**, déjà étudiée dans le dossier de relèvement du nom ;
- selon Moussia, **Marie-Louise de Casabianca (1855-1930) épouse Gaston d’Angelis**, raccord distinct entre les familles de Casabianca et d’Angelis.

Ces deux raccords ne doivent pas être confondus.
