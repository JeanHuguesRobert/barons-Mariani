# Registre médiatique — Sénatoriales 2026

## Objet

Ce sous-répertoire documente séparément :

1. ce que les médias et agrégateurs ont effectivement publié ;
2. les contacts établis avec les rédactions ;
3. les demandes de rectification et leurs suites ;
4. quelques cas de comparaison utilisés comme contrôles documentaires.

Il ne cherche pas à attribuer une intention éditoriale.

Principe :

```text
source primaire / événement
→ représentation publiée
→ transformation observable
→ demande éventuelle de correction
→ réponse / silence / état final
```

## Fichiers

- [`representations.yml`](representations.yml) — publications, formulations exactes, écarts observables et cas de comparaison ;
- [`contacts.yml`](contacts.yml) — courriels, brouillons, invitations et canaux presse retrouvés.

## Qualifications

Les qualifications portent sur des transformations documentaires, pas sur les intentions de leurs auteurs :

- `FIDÈLE`
- `VARIANTE`
- `NORMALISATION`
- `ERREUR_CERTAINE`
- `QUALIFICATION_EDITORIALE`
- `A_DETERMINER`
- `EXACT_A_LA_DATE`
- `NON_A_JOUR`
- `TENSION_AVEC_TRACE_PRIMAIRE`
- `SOURCE_A_REVERIFIER`

## Cas de comparaison

Les entrées marquées `comparison_case: true` servent uniquement à comparer des dimensions observables : délai de première reprise, entretien individuel, exposition du parcours et des propositions, vocabulaire de présentation.

Elles ne constituent ni un classement des candidats ni une conclusion sur les motivations des rédactions.

## Contact presse

Les coordonnées privées ou directes retrouvées dans des courriels ne sont pas reproduites ici lorsqu'une adresse générique publique suffit. Le registre peut indiquer « canal direct disponible dans Gmail » sans republier une donnée personnelle reçue dans un échange privé.

## Discipline

Une absence de publication retrouvée ne prouve pas une absence de publication réelle.

Une publication retrouvée ne prouve pas qu'une rédaction connaissait toutes les sources publiques disponibles.

Un contact envoyé à une rédaction établit l'envoi ; il n'établit pas automatiquement la lecture par un journaliste déterminé.

Le registre est incrémental, corrigible et destiné à permettre des Reality Tests de rectification.
