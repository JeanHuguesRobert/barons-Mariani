# Audit double lecture — v0.19

## Conclusion immédiate

**MUST non satisfait à ce stade.**

La v0.19 possède déjà :
- un résumé exécutif ;
- une chronologie narrative ;
- des matrices ;
- des bornes probatoires ;
- des développements pédagogiques ponctuels.

Mais elle n'applique pas encore de façon systématique, **dans chaque grande section**, les deux niveaux de lecture :
1. grand public ;
2. expert.

## Critère de conformité

Pour chaque grande section, on doit pouvoir identifier :

- **GP — Ce qu'il faut comprendre** ;
- **EXPERT — règle / source / pièce / qualification** ;
- **BORNE — ce qui est établi et ce qui ne l'est pas** ;
- **FONCTION — pourquoi cela compte pour le recours**.

Une simple introduction générale ne suffit pas.

## Règle de correction

Ne pas dupliquer mécaniquement tout le texte.

Pour chaque section :
- écrire d'abord la version **GP** en langage courant ;
- faire suivre d'un bloc **EXPERT** plus compact et référencé ;
- faire vérifier que les deux expriment exactement la même proposition ;
- conserver une seule source de vérité pour les faits et pièces.

## Test de régression

Une réécriture GP est un échec si elle :
- simplifie au point de supprimer une réserve ;
- transforme une analogie en règle ;
- masque une pièce adverse ;
- transforme UNKNOWN en fait ;
- ajoute une intention non prouvée.

Une réécriture expert est un échec si elle :
- devient incompréhensible hors du Corpus ;
- omet le contexte nécessaire pour comprendre le grief ;
- suppose connue une convention locale non définie.
