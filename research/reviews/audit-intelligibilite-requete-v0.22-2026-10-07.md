# Audit intelligibilité — v0.22

## Principe

Le critère n'est pas la brièveté.

Le critère est la facilité de compréhension.

Une explication plus longue est meilleure si elle :
- rend les prémisses visibles ;
- découpe les étapes ;
- réduit les ambiguïtés ;
- évite au lecteur de reconstruire le raisonnement ;
- conserve toutes les réserves juridiques et probatoires.

## Résultat

La v0.22 améliore nettement la lisibilité par **décomposition**, non par compression.

Elle conserve :
- la double lecture grand public / juriste junior ;
- le Principe de Talleyrand ;
- les niveaux de preuve ;
- les objections adverses ;
- les UNKNOWN.

Elle développe plusieurs passages qui étaient auparavant trop condensés.

## Phrase d'ouverture

La requête commence désormais par :

> **Obtenir le respect, en Corse comme ailleurs, réclame d’en manifester ; le mépris appelle le mépris.**

Cette phrase est assumée par le requérant.

Elle est immédiatement cadrée.

Le texte précise qu'elle ne vise aucune personne.

Il la présente comme une règle de réciprocité institutionnelle.

## Dernier contrôle recommandé

Avant gel :
- relire chaque « cela / ceci / donc / ainsi » ;
- vérifier chaque acronyme à sa première occurrence ;
- conserver les répétitions utiles lorsqu'elles évitent un retour en arrière ;
- ne supprimer une explication que si sa suppression ne transfère aucun effort cognitif au lecteur ;
- vérifier que les blocs pédagogiques ne modifient aucun niveau de certitude.
