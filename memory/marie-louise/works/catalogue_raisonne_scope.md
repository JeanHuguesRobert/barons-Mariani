# Catalogue raisonné de l’œuvre de Marie-Louise

## Principe

Dans ce catalogue, **œuvre** est employé au sens large de ce qu’une personne a créé, accompli, entrepris, transformé, transmis ou laissé comme trace, comme dans l’expression « l’œuvre de Napoléon ».

Le catalogue ne se limite donc pas aux œuvres d’art au sens traditionnel. Il peut inclure, lorsqu’elles sont suffisamment documentées :

- œuvres artistiques ;
- productions intellectuelles ;
- textes, images, vidéos et créations numériques ;
- performances, happenings et interventions situées ;
- actions sociales, civiques ou politiques ;
- réalisations concrètes ;
- projets inachevés ou empêchés ;
- contributions à des œuvres ou actions collectives.

Cette inclusion dans **l’œuvre de Marie-Louise** ne signifie pas qu’un élément soit automatiquement qualifié d’**œuvre d’art**. La qualification artistique constitue une propriété distincte, à documenter.

## Deux ensembles conceptuels

### L’œuvre de Marie-Louise

- œuvre artistique ;
- œuvre intellectuelle ;
- œuvre sociale ;
- œuvre politique ;
- interventions et actions situées ;
- réalisations concrètes ;
- projets et œuvres inachevés ;
- contributions à des œuvres collectives.

### Documentation de l’œuvre

- originaux ;
- fichiers et reproductions ;
- archives ;
- correspondances ;
- témoignages ;
- sources institutionnelles ;
- traces numériques.

Un document qui atteste l’existence d’une œuvre n’est pas nécessairement l’œuvre elle-même.

## Trois questions à conserver séparément

Pour chaque entrée, le catalogue doit distinguer au minimum :

1. **ce qui a existé ou a été accompli** ;
2. **ce qui est actuellement accessible ou localisé** ;
3. **sur quelles preuves repose chaque affirmation**.

Une œuvre perdue, détruite, inaccessible ou connue seulement par témoignage peut donc être cataloguée sans être assimilée à sa documentation.

## Types d’entrée recommandés

- `artwork` — œuvre artistique matérielle ou immatérielle ;
- `text` — texte créatif ou intellectuel ;
- `audiovisual` — vidéo, film, animation, stop motion, création sonore ou numérique ;
- `performance` — performance, happening, action artistique ou événement éphémère ;
- `situated-intervention` — intervention dans un lieu, un contexte social ou politique donné ;
- `social-action` — action sociale ou solidaire ;
- `political-action` — action ou initiative politique ;
- `project` — projet documenté, achevé ou non ;
- `collective-contribution` — contribution individualisable à une action ou œuvre collective ;
- `work-corpus` — ensemble d’œuvres ou productions encore non individualisées ;
- `process-trace` — esquisse, carnet, brouillon ou autre trace de processus.

Le champ `artistic_status` doit rester distinct du `work_type`. Valeurs utiles : `established`, `probable`, `possible`, `not-claimed`, `unknown`.

## Discipline documentaire

Le catalogue applique la discipline de `memory/marie-louise/carte.md` :

- `VOICE` : parole ou œuvre directement attribuable à Marie-Louise ;
- `TRACE` : pièce primaire contemporaine ;
- `THIRD-PARTY` : témoignage, article ou document provenant d’un tiers ;
- `FACT` : fait suffisamment établi par les traces disponibles ;
- `INFERENCE` : interprétation ou reconstruction ;
- `UNKNOWN` : lacune ou point non résolu.

La provenance et le statut épistémique doivent rester distincts.

## Échelle complémentaire de disponibilité / preuve

- **A** — original ou fichier source identifié ;
- **B** — reproduction fiable ;
- **C** — trace contemporaine établissant l’existence ;
- **D** — témoignage nominatif postérieur ;
- **E** — souvenir ou indication non encore corroborée ;
- **X** — hypothèse de recherche.

Cette échelle ne remplace pas `VOICE / TRACE / THIRD-PARTY / FACT / INFERENCE / UNKNOWN`.

## ZAD — entrées à documenter

Deux interventions de Marie-Louise dans des ZAD sont actuellement connues par `ASSERTION-JHR` :

- une ZAD à proximité de Nantes ;
- une autre ZAD dans le sud de la France.

Elles doivent être traitées comme deux entrées séparées de type `situated-intervention`.

Leur présence dans le catalogue ne préjuge pas de leur qualification comme œuvres d’art. Leur éventuelle dimension artistique devra être établie à partir des traces disponibles : intention explicite, production visuelle ou performative, documentation, témoignages, contexte et formes mobilisées.

## Règle générale

Le catalogue raisonné de l’œuvre de Marie-Louise vise à reconstruire scientifiquement **ce qu’elle a créé, accompli, tenté, transformé ou mis en mouvement**, en conservant explicitement les incertitudes, les absences et les contradictions documentaires.
