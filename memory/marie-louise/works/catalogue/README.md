# Catalogue raisonné de l’œuvre de Marie-Louise — registre

Ce dossier contient la représentation machine-readable et les journaux de recherche du catalogue raisonné défini par `../catalogue_raisonne_scope.md`.

## Fichiers

- `schema.yml` — schéma canonique des entrées ;
- `entries.yml` — registre initial ;
- `entries-gmail-2026-09-17.yml` — entrées et pistes ajoutées par la campagne Gmail du 17 septembre 2026 ;
- `gmail_campaign_2026-09-17.md` — journal humain de la campagne Gmail correspondante.

## Règle d’intégration

Une découverte peut être enregistrée avant que l’objet ou le fichier original soit retrouvé. Il faut conserver séparément :

1. l’existence ou l’accomplissement de l’élément ;
2. son accessibilité actuelle ;
3. les preuves qui soutiennent chaque affirmation.

Les suppléments datés servent au travail incrémental. Ils pourront être consolidés périodiquement dans `entries.yml` sans changer les identifiants `MLR-*` déjà attribués.
