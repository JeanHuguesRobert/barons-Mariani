# Marie-Louise — histoire électorale documentée 2017–2024

## Objet

Ce dossier consolide les traces électorales concernant **Marie-Louise Isabelle Garance Robert** entre 2017 et 2024. Il sert de couche documentaire sous `memory/marie-louise/carte.md` et sous les projections éditoriales de `projects/suicide-corse/`.

Il ne cherche ni à reconstruire une psychologie politique de Marie-Louise, ni à attribuer rétrospectivement une causalité à sa mort. Il documente des actes, rôles, formulaires, bulletins, échanges et suites institutionnelles.

## Discipline

Les notes distinguent :

- `VOICE` — parole ou consentement directement attribuable à Marie-Louise ;
- `TRACE` — pièce primaire contemporaine ;
- `THIRD-PARTY` — pièce ou affirmation tierce ;
- `FACT` — fait suffisamment établi ;
- `INFERENCE` — interprétation ;
- `UNKNOWN` — élément non résolu.

Une source Gmail peut servir de pointeur documentaire sans que son contenu privé soit automatiquement publiable. Toute citation ou réutilisation substantielle d'une correspondance privée reste soumise à un **disclosure gate** distinct.

## Point transversal : noms et représentation

Les pièces montrent plusieurs identités publiques ou électorales :

```text
Marie-Louise Isabelle Garance ROBERT
→ Marie-Louise d'Angelis
→ Baronne ML Mariani
→ baronne Marie-Louise MARIANI
```

Ces formes doivent être conservées avec leur **date, leur document et leur contexte**. Elles ne doivent pas être normalisées rétroactivement en un nom unique ni supposées équivalentes juridiquement.

Le cas 2020 est particulièrement instructif : le nom civil de la remplaçante enregistrée et le nom déclaré pour publication sur le bulletin sont différents. Cette distinction est documentée dans `2020-senatoriales.md`.
