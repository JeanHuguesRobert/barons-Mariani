# Marie-Louise — matrice longitudinale des possibles

## 1. Objet

Cette matrice constitue un premier **Reality Case longitudinal** pour l'issue #47 de *Suicide Corse*.

Elle vise à cartographier avec le même niveau d'exigence :

- ce qui ouvre un possible ;
- ce qui le maintient ;
- ce qui crée une friction sans le fermer ;
- ce qui ferme effectivement une branche ;
- ce qui permet une réouverture ou une bifurcation ;
- ce qui ajoute une charge ou une contrainte sans que l'on puisse encore parler de fermeture.

Elle ne constitue ni une biographie complète ni une analyse causale du suicide.

## 2. États dynamiques

| État | Sens |
|---|---|
| `CAPACITY` | capacité déjà exprimée ou exercée ; ne signifie pas qu'un acteur extérieur l'a « ouverte » |
| `OPEN` | une branche auparavant non matérialisée devient concrètement accessible |
| `MAINTAIN` | une branche déjà ouverte est maintenue, consolidée ou rendue durable |
| `FRICTION` | obstacle ou coût documenté ; la branche n'est pas démontrée comme fermée |
| `CLOSE` | une branche précise devient effectivement indisponible |
| `REOPEN` | une branche comparable ou dérivée redevient praticable après une fermeture |
| `LOAD` | charge, obligation ou consommation de ressources documentée ; ne vaut pas fermeture |
| `UNKNOWN` | direction ou conséquence insuffisamment documentée |

Une même séquence peut changer d'état au cours du temps.

## 3. Discipline causale

Chaque ligne distingue :

~~~text
événement observé
≠
dynamique du Possible
≠
mécanisme causal
≠
conséquence observée
≠
conséquence contrefactuelle
~~~

Une fermeture ne doit pas être attribuée à une « Machine à Empêcher » sans mécanisme observable.

Une ouverture ne doit pas être attribuée à une « Machine à Explorer » sans facilitateur ou capacité identifiable.

## 5. Premiers enseignements méthodologiques

### 5.1 Une friction n'est pas une fermeture

Le cas Nantes 2017 est un test important :

~~~text
menace sur le statut étudiant
→ FRICTION documentée

mais

2e année attestée ensuite
→ branche MAINTENUE
~~~

Une méthode qui aurait codé décembre 2017 comme `CLOSE` aurait produit un faux positif.

### 5.2 Une fermeture locale n'est pas une fermeture globale

Le refus sénatorial de 2020 ferme une branche très précise :

~~~text
remplaçante sénatoriale 2020
~~~

mais ne ferme pas la capacité politique générale. En 2022, Marie-Louise devient candidate titulaire.

Cela fournit un exemple de :

~~~text
CLOSE local
→ REOPEN dans le même domaine
→ EXPANSION du rôle
~~~

### 5.3 Une charge n'est pas une fermeture

L'aidance en 2024 est directement attestée.

Mais :

~~~text
LOAD
≠
CLOSE
~~~

tant que l'on ne dispose pas d'une trace montrant quelles capacités ou options ont été effectivement compromises par cette charge.

### 5.4 Les mécanismes de recours peuvent rouvrir une branche

Le dossier électoral 2024 montre :

~~~text
grief / dommage allégué
→ alerte ou recours
→ nouveau canal
~~~

Le canal peut ensuite :

- fonctionner ;
- échouer ;
- être relayé ;
- se fermer pour une raison procédurale.

Il faut donc cartographier le **cycle de vie du recours**, pas seulement le grief initial.

### 5.5 Les ouvertures constituent des contrôles

CPES, Nantes, bourses, exposition, publication, réseaux et candidatures permettent d'étudier les périodes où des institutions ou ressources ont effectivement augmenté la capacité d'agir.

Elles servent de contrôles pour tester les épisodes de fermeture supposée.

## 6. Hypothèses de travail produites par la matrice

Ces propositions sont des hypothèses de recherche, non des conclusions biographiques.

### H1 — Buffers de capacité

Une friction peut être absorbée lorsque des buffers existent :

- ressources financières ;
- bourse ;
- entourage ;
- statut déjà acquis ;
- pluralité de canaux ;
- capacité de correction ;
- temps disponible.

À tester sur Nantes 2017–2019.

### H2 — Fermeture en cascade

Une fermeture devient potentiellement plus grave si elle détruit non seulement une option mais aussi une **capacité générative** donnant accès à plusieurs options futures.

Aucun épisode Marie-Louise n'est encore qualifié ainsi avec un niveau de preuve suffisant.

### H3 — Réouverture

Une capacité antérieure peut faciliter la réouverture d'une branche après un échec local.

Le passage :

~~~text
refus du rôle de remplaçante en 2020
→ candidature titulaire en 2022
~~~

est un candidat propre à cette étude.

### H4 — Channel resilience

Une institution ou un système est plus robuste lorsque l'échec d'un canal n'annule pas l'accès à la fonction recherchée.

Le 5 juillet 2024 fournit un cas où certains destinataires échouent tandis qu'un service judiciaire relaie le message.

### H5 — Charge et exergie cognitive

Une charge d'aidance peut consommer du temps, de l'attention, de l'énergie ou des ressources sans fermer immédiatement une option.

La chaîne :

~~~text
LOAD
→ ressources consommées
→ capacité disponible réduite
→ option éventuellement compromise
~~~

doit être démontrée maillon par maillon.

## 7. Lacunes prioritaires révélées par la matrice

1. **Été 2024** : c'est de loin la plus grande zone noire causale.
2. **Villa Arson** : décision primaire, niveau d'entrée, inscription et fréquentation.
3. **Interruption des études** : date, nature, mécanisme et éventuel lien avec l'aidance.
4. **Nantes 2017** : résolution de la friction administrative.
5. **Vidéos** : récupération des fichiers de *L'altérité en soi* et *photoromanJulie*.
6. **Recours 2024** : réponses Arcom, parquet, tribunal et autres suites avant le 17 septembre.
7. **Ressources/buffers** : documenter non seulement les obstacles mais les soutiens matériels, humains et institutionnels.

## 8. Règle pour la v0.2

Aucune ligne ne doit passer :

~~~text
FRICTION → CLOSE
LOAD → CLOSE
correlation → causation
THIRD-PARTY → VOICE
~~~

sans nouvelle pièce ou justification explicite.

La prochaine version devrait ajouter pour chaque ligne :

- un identifiant stable ;
- un score de certitude ;
- un champ `counterevidence` ;
- un champ `alternative_explanations` ;
- un champ `descendant_possibles`;
- éventuellement une représentation machine-readable YAML/JSON pour Cogentia.
